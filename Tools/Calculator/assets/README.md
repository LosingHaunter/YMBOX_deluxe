# 界面资源来源

计算器界面样式参考 Animal Island UI 1.0.16（作者 guokaigdg，MIT 许可证，原文见 `licenses/animal-island-ui-LICENSE.txt`）。

- `styles.css`、`ymbox-config.css`：按参考库的 Button、Input、Select、Tabs、Collapse、Card、Checkbox 视觉规则适配现有 HTML 控件。
- `fonts/`：随参考库分发的 Nunito 与 Noto Sans SC 字体，用于离线加载。两者均采用 SIL Open Font License 1.1，许可原文分别见 `licenses/nunito-OFL.txt`（Copyright 2014 The Nunito Project Authors）和 `licenses/noto-sans-sc-OFL.txt`（Copyright 2014-2021 Adobe，保留字体名称 "Source"）。
- `img/icon-leaf.png`、`img/divider-line-teal.svg`：来自参考库的图标与分隔线素材。
- `icon/`：YMBOX 工具箱应用图标。

应用运行时不需要访问上述来源；参数计算、方案保存和写入模型由本工具自身的程序完成。

# UI Asset Sources

The calculator UI styling is based on Animal Island UI 1.0.16 (by guokaigdg, MIT license; full text in `licenses/animal-island-ui-LICENSE.txt`).

- `styles.css`, `ymbox-config.css`: adapt the existing HTML controls to the visual rules of the reference library's Button, Input, Select, Tabs, Collapse, Card and Checkbox.
- `fonts/`: the Nunito and Noto Sans SC fonts distributed with the reference library, used for offline loading. Both are licensed under the SIL Open Font License 1.1; the license texts are in `licenses/nunito-OFL.txt` (Copyright 2014 The Nunito Project Authors) and `licenses/noto-sans-sc-OFL.txt` (Copyright 2014-2021 Adobe, with Reserved Font Name "Source").
- `img/icon-leaf.png`, `img/divider-line-teal.svg`: icon and divider artwork from the reference library.
- `icon/`: the YMBOX toolbox application icon.

The application does not need to access these sources at run time; parameter calculation, profile saving and writing to the model are done by the tool's own code.
